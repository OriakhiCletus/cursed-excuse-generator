# The Ultimate Excuse Debunker & Alternate Reality Generator (A Cursed Duality Machine)

https://cursed-excuse-generator.vercel.app/

## What does it do?

I built this cursed machine as the internet's last stand against accountability. It generates outrageously specific excuses for *anything* and then attempts to debunk them, often failing so badly it creates alternate realities where excuses become immutable facts. I made it a 2-in-1 experience of generating and breaking logic, all wrapped in a beautiful glitchy interface.

## How did I build it?

I used pure chaos and the simplest tech stack possible: HTML, CSS, and JavaScript. I used no frameworks, no build steps, just raw, unfiltered web technologies mashed together with cursed logic. I intentionally flawed the JavaScript to create the "broken" behavior described above.

## Why is it cursed/awesome?

* **Cursed:** I made it have two "Generate Excuse" buttons that do different things (one works normally-ish, the other shouts and makes text bigger). The "Debunk" button doesn't debunk; it creates more chaos. I intentionally broke the logic.
* **Awesome:** I kept it simple, chaotic, potentially useless, and I think it perfectly embodies the spirit of building something "so wrong it might just be right." It's a love letter to bizarre ambition, which is what I aimed for.

## Features

* I made it so it can generate an infinite number of ridiculous excuses.
* I added the "Alt" button to enter an alternate reality where excuses get shouted (visually).
* I added the "Debunk" button to witness the logic-breaking chaos I created.
* I made the text size increase with each "Alt" click (a feature, not a bug!).
* I used pure HTML/CSS/JS - no build tools, just raw cursed power.

## Local Development and Use

1. Clone the repo.
2. Open `index.html` in you browser.
3. Embrace the chaos I built.
